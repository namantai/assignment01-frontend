# Assignment #1 — HTML & CSS Basics

This project is an HTML and CSS assignment for practicing basic web development.

## Tasks

The project includes:

* Task 1 — Personal Webpage
* Task 2 — Simple Webpage Layout
* Task 3 — Tribute Page
* Task 4 — CSS Table and Form
* Task 5 — Midterm Project Wireframe

## Technologies

* HTML5
* CSS3

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation bar to move between the tasks.
